# My Portfolio

Plain HTML, CSS, and JavaScript. No build step, so it works on GitHub Pages, Vercel (framework "Other"), and Firebase Hosting.

## Replace before publishing
1. Search index.html for ANNE PURCA, your.email@example.com, YOUR-USERNAME, YOUR-PROFILE and every [bracketed] placeholder.
2. Add your photo as images/profile.jpg and swap in the <img> line shown in the comment inside the About section.
3. Add project screenshots (images/project1.png and so on) and replace each .shot placeholder with an <img>. Update each "View project" link.
4. Test on a narrow window and your phone, then follow the guide's hosting steps.
